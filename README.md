# Stream-Scheduler
Ada Computer Science Project - Stream Scheduler

In this project, you will design and build a program called Stream Scheduler.\n 
The program will help a content creator plan a livestream where they review upcoming games. 
Throughout this project, you will practise breaking down a problem into inputs, processes, and outputs, and then turning those requirements into working Python code.

This project is a full systems lifecycle project. You will:
  Create a set of requirements based on the analysis of the Stream Scheduler program
  Create a design for the Stream Scheduler program, including structure diagrams, pseudocode, and flowcharts
  Create the program using Python
  Test the program
  Evaluate the program against the initial requirements
